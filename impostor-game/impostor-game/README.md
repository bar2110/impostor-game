# מי האימפוסטר? 🎭

משחק חברתי בעברית, מותאם לטלפון, עם חדרים בזמן אמת, קוד כניסה, שאלות פרטיות, תורות, דיון, הצבעות ודירוג.

## הפעלה

דרוש Node.js 18 ומעלה. **אין צורך להתקין חבילות.**

```bash
node server.js
```

פותחים בדפדפן `http://localhost:3000`.

### משחק בכמה טלפונים באותה רשת Wi-Fi

המחשב שמריץ את השרת והטלפונים צריכים להיות באותה רשת. מוצאים את כתובת ה-IP המקומית של המחשב (ב-Windows: `ipconfig`) וגולשים מהטלפונים לכתובת בסגנון `http://192.168.1.23:3000`. יש לאפשר גישה ל-Node.js בחומת האש לפי הצורך. הקוד המוצג הוא דוגמה בלבד; השתמשו בכתובת המחשב שלכם.

### משחק מרחוק / באינטרנט

יש לפרוס את הפרויקט על שרת Node.js שתומך בתהליך שרץ באופן רציף (למשל VPS או שירות hosting תואם). יש להגדיר משתנה PORT בהתאם למארח ולפתוח את כתובת ה-HTTPS של השרת. המשחק לא נפרס לאינטרנט מתוך השיחה הזאת.

## כללים

- יצירת חדר עם שם מנהל, מספר סבבים (ברירת מחדל 5), זמן דיון (ברירת מחדל 3 דקות).
- התחברות מכל טלפון באמצעות קוד בן 6 ספרות ושם שחקן. 3–16 שחקנים.
- כל שחקן מקבל שאלה פרטית, ללא תווית 'אימפוסטר'. אחד מקבל שאלה שונה.
- השחקנים מקלידים תשובה מספרית, אומרים את המספר בקול לפי תור ולוחצים 'סיימתי'.
- לאחר התורות השאלה הרגילה נחשפת ודיון מוגבל בזמן מתחיל.
- הצבעה אחת; אין הצבעה עצמית. במקרה תיקו — הצבעה חוזרת בין המובילים; אם שוב תיקו אין הדחה.
- +100 למי שהצביע נכון בהצבעה הראשונה; +200 לאימפוסטר שלא הודח.
- יש שני סוגי זוגות שאלות (דומות ושונות) והמערכת דואגת לשלב כל סוג לפחות פעם אחת במשחק של 3 סבבים ומעלה.

## מגבלות גרסה ראשונה

- מצב המשחק נשמר בזיכרון השרת בלבד, ולכן הפעלה מחדש מאפסת את כל החדרים.
- ההתחברות מבוססת אסימון שמור בדפדפן; רענון באותו דפדפן משמר את השחקן כל עוד השרת עובד.
- החדרים פגים אחרי 24 שעות. אין כרגע מערכת חשבונות או מסד נתונים.
- נדרש שרת נגיש לכל השחקנים; פתיחת HTML ישירות כקובץ לא מספיקה.
- אם אחד השחקנים מתנתק באמצע, השלב יכול להמתין לו; בגרסה עתידית נוסיף יכולות התאוששות והסרה באמצע המשחק.
- כאשר שחקן מועמד בתיקו והוא עצמו מצביע, הוא יכול להצביע רק למועמד אחר. בתיקו חוזר אין מודח.

- `public/style.css` — עיצוב מובייל סגול
- `public/app.js` — צד לקוח, ממשק ותזמון
